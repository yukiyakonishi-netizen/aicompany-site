取得する情報

本アプリは Google の OAuth 認証を通じて、運営者自身の YouTube チャンネルへ動画を投稿する権限（YouTube Data API のアップロード権限）のみを取得します。

利用目的

取得した権限は、運営者が制作した動画のアップロード、サムネイル設定、公開日時の設定にのみ使用します。

保存と共有

認証トークンは運営者が管理する非公開の環境にのみ保存し、第三者へ提供・販売しません。第三者の個人情報は収集しません。

Google API サービスの利用

本アプリによる Google API から受け取った情報の使用は、限定的使用の要件を含む Google API Services User Data Policy に準拠します。

権限の取り消し

Google アカウントの権限設定からいつでもアクセスを取り消せます。
